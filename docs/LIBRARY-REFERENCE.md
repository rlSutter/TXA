# TXA Standard Library Reference

Generated by `tools/gendocs.py` from the library's source (`lib/`); do not edit by hand. The library is TXA source like a game's: a game includes it with `INCLUDE "DSK1.STDLIB"` and supplies `ROUTINE Initialise`, which sets `location` (and anything else the game needs) before the first look. Everything here can be changed by the game: a property on an object, a rule, a hook, or the library's own source.

## 1. How a turn runs

The player types a command; the parser (`lib/parser.txa`) reads it into an action, a `noun` and a `second`, asking which one is meant when a name fits several things. Then `Perform` runs, in this order, stopping as soon as one of them returns TRUE (a string in a rule prints and counts as TRUE):

1. if the command was an order to a character ("BRANNOCK, GO NORTH"), that character's `ORDERS`;
2. the game's `beforehook`, if it set one;
3. the room's `BEFORE`, then the `noun`'s `BEFORE`;
4. the action routine (`TakeSub`, `OpenSub` ...), which does the action and says so;
5. the room's `AFTER`, then the `noun`'s `AFTER` (TRUE: their message replaces the usual one);
6. the game's `afterhook`.

Then the turn ends (`EndTurn`): every daemon runs, timers count down (a timer at 0 runs its `TIME_OUT`), the room's `EACH_TURN` runs, then the game's `endturnhook`; a change of score is announced, and the status line is redrawn. Meta verbs (SAVE, UNDO, SCORE, RECORD and the like) take no turn. The game ends when `deadflag` is set: 1 dead, 2 won; `endmessage` replaces the usual words.

A rule is written in a `BEFORE` or `AFTER` block, a case per action. From the sample game, the great lens: BURN is refused until the lamp has oil and the player has matches, and then it scores, plays the horn and wins the game (quoted from `samples/lamplight.txa`):

```
OBJECT Lens "great lens" IN LampRoom
  NAME "great" "lens" "lamp" "light" "wick"
  HAS static scenery
  DESC
    IF lamp_fuelled
      PRINT "The reservoir is full and the wick is ready."
    ELSE
      PRINT "A tower of glass prisms around a wick. The oil reservoir is dry."
    END
    RETURN TRUE
  END
  BEFORE
    Burn:
      IF NOT lamp_fuelled
        PlaySound(MatchSound)
        PRINT "The wick is dry; it won't take a flame."
        RETURN TRUE
      END
      IF Matches NOTIN player
        PRINT "You have nothing to light it with."
        RETURN TRUE
      END
      score = score + 10
      end_picture = EndPic
      end_music = EndTune
      PlaySound(HornSound)
      PRINT "You strike a match and touch it to the wick. The flame catches, steadies, and the great lens takes it, throwing a slow beam out across the water. Far out, a ship's horn answers."
      deadflag = 2
      RETURN TRUE
  END
END
```

## 2. Characters

An object with `animate` is a person or creature. ASK, TELL, GIVE, SHOW, ATTACK, KISS and ANSWER go to its `LIFE` property (with `noun`, `second` and the topic set); returning TRUE means it has answered. Orders go to `ORDERS`. A character can be given things, follow the player (move it in a daemon), or change the map (exits are properties, and can be set at any time).

## 3. The world

- **Light**: a room is lit if it has `light`, or if something `lit` or `light` is in it where the player can see it; in the dark the player sees nothing and cannot find things.
- **Doors**: an object with `door` in an exit leads to its `DOOR_TO`; give it `openable`, `lockable`, `locked` and a `WITH_KEY` as needed. A door in two rooms lists them in `FOUND_IN` (a floating object), as does any object present in several rooms (the sea, a river).
- **Exits**: every room has all twelve (N to OUTSIDE); each is a room, a door, or a routine that decides (and may print why not). A room's `CANT_GO` is said for exits that lead nowhere.
- **Containers and supporters**: `container` and `supporter`, with `open`, `openable`, `transparent` and a `CAPACITY`.
- **Pictures and music**: a room's `PIC` is shown and its `TUNE` played while the player is there; `ShowPicture` and `PlayMusic` do it directly, `PlaySound` plays an effect. `title_picture`, `title_music`, `end_picture` and `end_music` dress the title page and the end.
- **Score**: add to `score`; set `max_score` to show it out of a total.
